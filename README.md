# Niemiecki dla Polaka

Aplikacja (PWA) do nauki języka niemieckiego dla osób polskojęzycznych.

- **Ścieżka A1 → C2**: 47 lekcji, ponad 700 słów; kolejna lekcja otwiera się po poznaniu 70% poprzedniej albo po zdanym teście.
- **Trening z automatycznym sprawdzaniem**: najpierw karta ze słowem, potem sprawdzenie: ABCD w obie strony, zdanie z luką, rozpoznawanie ze słuchu, wpisywanie, wybór rodzajnika. Powtórki układa algorytm SM-2.
- **Der · die · das**: rodzajniki w kolorach, quiz rodzajników i liczby mnogiej.
- **Słuchanie**: słowa, zdania, pisownia ze słuchu, „prawda czy fałsz”, czytanki A2–C2.
- Wymowa (pary minimalne), fałszywi przyjaciele, gramatyka kontrastowa, dialogi z shadowingiem, dyktando.

Budowanie: `python build.py` → `Niemiecki_dla_Polaka.html` (jeden plik) i `docs/` (GitHub Pages / instalacja na telefonie).
